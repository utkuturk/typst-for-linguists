# Typst for Linguists

A small GitHub Pages project for notes, examples, and practical guides on using [Typst](https://typst.app/) for linguistics.

I am starting with **formal semantics**, with a focus on writing clean handouts and papers that include:

- semantic denotation brackets
- lambda notation and type notation
- derivations and rule labels
- numbered linguistic examples
- syntax and semantic trees

## Start Here

The first guide in the project is:

- [Typst for Linguists: Formal Semantics Edition](./semantics/semantics.pdf)

If you want the source file, see:

- [Typst source](./semantics/semantics.typ)

## What This Project Is For

This repo is meant to become a compact collection of Typst materials for linguists, especially people working in:

- semantics
- syntax
- field methods
- classroom handouts
- article and thesis writing

The goal is not just to show Typst syntax, but to build reusable patterns for actual linguistics workflows.

## Why Typst

Typst is a good fit for linguistics because it is:

- cleaner to read and write than large LaTeX preambles
- fast to compile
- good for reusable functions and document structure
- flexible enough for examples, trees, glosses, and formal notation
